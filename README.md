# CafeHub 🍔

CafeHub is a simple food ordering web application built using Flask. It allows users to browse food items, add them to a cart, place orders, and view order history. It also includes a basic real-time chat feature.

## Features

- User registration and login system
- Food menu display
- Add to cart functionality
- Checkout and order creation
- Order history page
- Basic real-time chat using Socket.IO
- Responsive design for mobile and desktop

## Tech Stack

- Flask
- SQLite (SQLAlchemy)
- Flask-Login
- Socket.IO
- HTML, CSS, Bootstrap

## How it works

- Users can create an account and log in
- Browse available food items on the homepage
- Add items to cart and proceed to checkout
- View past orders in the orders page
- Chat feature allows basic real-time messaging

## Note

This project is built for learning purposes and demonstrates basic full-stack web development concepts using Flask.
